# 自动化扩展约定

当前仅支持用户导出 CSV，不调用 Amazon 或第三方 API，不自动变更广告。

未来可添加 amazon_ads.py、sp_api.py、sellersprite_import.py、xiyou_import.py；每个适配器输出模板相同字段，并保留来源文件、采集时间、账户时区、归因窗口、父子变体口径和估算标识。先在匿名样例验证列映射、单位、分页、限流、去重和重试。

凭证使用环境变量或 GitHub Secrets，不写入源码。真实数据任务应使用私有仓库及受限报告存储；不得直接复用当前公开 workflow 上传真实报告。定时采集、消息推送、竞价写入都尚未配置，接入时分别明确频率、授权与人工复核边界。
