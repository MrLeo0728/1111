# 每周运营与开发流程

1. 周一：更新竞品档案与价格快照。对比同子体、同件数和同优惠条件；记录图片、卖点和评论证据。记录动作时间，价格与销量同步变化只能提出原因假设。
2. 周二：导出已完成归因回补的同周期广告报表，保存原件在本地私有目录，映射模板并运行脚本。上周尚未回补数据标记暂定，不直接与成熟周期比较。
3. 周三：逐行复核“有花费无单”“高于目标/盈亏线”“可评估扩量”。低样本先观察；否词前确认搜索意图和历史贡献。调整竞价、预算、否词须人工在广告后台执行并记录。
4. 周四：维护 A–D 差异化决策。数量策略检查单位价与体积成本；款式策略检查场景覆盖与重复率；功能策略检查打样与质检；礼赠策略检查包装和原创性。先找消费者证据，再评分。
5. 周五：在 experiments 表登记一个主要变量的测试，明确基线、成功条件、利润/退货护栏、负责人和复盘日；收集结果后更新决策。

## 完整产品开发七步

市场/需求/竞品 → 视觉/卖点/价格机会 → A–D 四方案 → 商业40%/生产40%/IP20%筛选 → 所选方案设计简报及打样 → 已核实规格的英文标题、五点和图片计划 → 商标/版权/设计专利初查并反馈筛选。

当前仓库提供流程与记录工具，不包含完成的市场调查、工程图或IP检索。生成产品图案前先确定真实产品规格；英文销售文案只使用有证据的宣称。主图与类目要求在制作时查当期 Amazon 官方规则。
